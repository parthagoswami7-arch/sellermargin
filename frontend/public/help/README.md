# Seller Central screenshots

Drop your PNG/JPG captures here to have them appear in the "Show screenshot" dialog on the New Report page.

Expected filenames (any width, up to ~1200px looks best):

- `orders.png`             → All Orders report
- `payment.png`            → Settlement / Payment (Transaction) report
- `fba_returns.png`        → FBA Customer Returns report
- `easyship_returns.png`   → Easy Ship Returns / Manage Returns
- `fba_removal.png`        → FBA Removal Order Detail
- `ad_spend.png`           → Sponsored Products (Campaign) report

Until a file with the exact name is present, the dialog shows a friendly "Screenshot coming soon" placeholder — so partial coverage is fine.
